世嘉 Game Gear

世嘉 · 1990 · 约 ¥1200（1990 年售价折算） · 游戏机 · 编辑评分 7/10 · 用户评分 7.9/10（公开口碑整理值，非本站打分）

背光彩色大屏掌机先驱，代价是惊人的电池消耗。

客观评测

Game Gear 采用 3.58MHz Z80 处理器与 3.2 英寸背光彩色液晶屏，160×144 分辨率，4096 色调色板同屏 32 色，是 1990 年少见的全彩带背光掌机。8KB 主内存加 16KB 显存，性能接近世嘉 Mark III 主机，配立体声喇叭与三声道音频。实测画面色彩鲜艳、可视角度尚可，但 6 节 AA 电池续航仅 3-5 小时，长时间游戏机身明显发热，卡带最大 8Mb。

主观点评

在 Game Boy 的橄榄绿单色屏旁边，Game Gear 的彩色背光屏简直是来自未来。躲在被窝里玩《索尼克》不用蒙着被子打手电，立体声喇叭让 BGM 充满动感。代价是零花钱全喂了电池，出门必带一大包五号电池。它代表了世嘉不服输、用技术硬刚的倔强，是掌机史上浓墨重彩的彩色先驱，情怀分十足。

优点与不足

  • 背光彩色屏在昏暗环境也能游玩，远超同期 Game Boy
  • 内置立体声喇叭，音效体验掌机领先
  • 兼容 Master System 卡带，可玩范围大增
  • 6 节电池仅撑 3-5 小时，续航是硬伤
  • 机身厚重，长时间握持负担明显

参数规格

屏幕3.2 英寸背光彩色液晶屏，160×144，4096 色同屏 32 色
处理器Zilog Z80，3.58MHz
内存8KB 主内存 + 16KB 显存
音频立体声三通道 + 噪声，内置立体声喇叭（掌机首创）

手柄十字键 + 1/2 键 + Start，机身一体式

尺寸重量210×113×38mm，约 400g（含电池）
首发大作《索尼克》《Columns》《牧场物语 GG》
